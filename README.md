- отключен принудительное переключение на альбомную ориентацию при воспроизведении видео;

------------
Автор оригинального приложения Zona использует два набора серверов.
Один для РФ, а другой для остального мира.
Сервера для РФ недоступны из мира, а сервера из мира недоступны для РФ.
Во время работы приложения автор пытается определить какой набор серверов использовать.
Но ИМХО делает это не всегда удачно. Что приводит к "внезапной" недоступности источников и постеров.
Всё это усугубляется применением VPN.

Для решения этой проблемы мне кажется, что нужно (вынужденно) разделить приложение на версию для РФ, для мира и оставить исходный набор.
Версии отличаются только набором серверов. В одном набора только для РФ, а в другом только для мира и в третьем как в оригинале (т.е. оба набора серверов).

Версии будут именоваться:

Наименование APK  | Описание
-|-
FreeZona_3.0.XX_ultra_aligned.apk  | версия как в оригинале
FreeZona_3.0.XX_RU_ultra_aligned.apk  | версия для РФ
FreeZona_3.0.XX_World_ultra_aligned.apk  | версия для мира

### И ещё...
Многие спрашивают почему не сохраняется "озвучка" или почему выбирается озвучка не по умолчанию.
При старте фильма или перехода не следующую серию приложение получает с серверов Zona список источников текущего видео.
После чего запускается фоновый процесс проверки источников на "живость" и вычитывания разрешения видео и другой информации.
Из того, что удалось проверить в течении первых 5-10 секунд выбирается наиболее подходящий источник ("озвучка") и начинается показ видео.
Не обязательно выбирается тот, который вы выбрали по умолчанию, а тот который удалось проверить в первые 5-10 секунд.
Во время показа видео фоновый процесс проверки источников продолжается до тех пор пока не проверятся все источники.
Поэтому полный перечень источников будет доступен позже, пока не проверит все источники.
На мой взгляд не очень удачная реализация, но так решил автор.

Ксли во время воспроизведения видео переключается источник, то это происходит чаще всего из-за того, что текущий источник "внезапно" стал недоступен и приложение пытается переключиться на другой.
